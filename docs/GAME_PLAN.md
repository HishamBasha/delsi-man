# Delsi Man — Game Plan

Single source of truth. Every session starts and ends here.

## Vision
A Pepsi-Man style endless-runner through a stylized Yemeni city: 1,800m, six
checkpoint sections, lollipops, bottles, hazards, chase finish.

## Rules of engagement
- One milestone at a time; nothing is "done" without a passing test run AND a screenshot in `docs/shots/`.
- Big ideas get approved as text here first, then built.
- You judge screenshots: yes / fix / next.
- You drop asset files into the folders below; I prep and wire them.

## Folder map
| Folder | What lives there |
|---|---|
| `assets/models/{buildings,vehicles,nature,people,props,hero}` | 3D models + textures |
| `assets/ui` | Logos, UI art |
| `audio/music`, `audio/sfx` | Sound files (drop here) |
| `fonts` | Fonts |
| `scenes/levels` | Playable levels (hand-authored) |
| `scenes/prefabs` | Reusable placed props |
| `scenes/hazards`, `scenes/ui` | Hazard scenes, UI scenes |
| `scripts` | Gameplay code (game, runner, hero, course, models…) |
| `tools/{probes,shots,blender}` | My verification + Blender pipeline |
| `data` | Level + flavor JSON |
| `docs` | Plans, reports, screenshots |
