# Asset and licensing register

All code, course layout, geometry and synthesized sound cues in this project were newly created for this task. No Pepsiman ROMs, code, levels, models, audio, images or extracted resources were used.

`Art.box`, `Art.cylinder`, `Art.hero`, `Art.bottle`: original procedural stand-ins. Delsi naming is used for the requested concept; trademark/packaging authorization is not verified. Official artwork must be supplied and cleared before commercial distribution.
